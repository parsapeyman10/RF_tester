# چک‌لیست تست واقعی روی سخت‌افزار

نسخه: فریمور ESP32 **V2.2** — کامیت `d55d3a8`

---

## ۰) قبل از فلش — دو تنظیم

در `esp32_controller_FIXED.ino`، بالای فایل:

```cpp
// اگر مودم/هات‌اسپات دارید (اختیاری؛ خالی هم باشد از ساعت گوشی استفاده می‌شود)
const WifiCred TIME_NETWORKS[] = {
  // { "MyModem", "modem-password" },
};

// نگاشت رله -> BCM . اگر سخت‌افزار شما «رله۱=Open برای هر دو» است، عوضش کنید
const ChannelConfig CHANNELS[] = {
  { "BCM1", 2, 13, 15 },
  { "BCM2", 4, 16, 17 },
};
```

`DEBUG_MODE` را فعلاً روی `1` بگذارید تا لاگ کامل ببینید؛ بعد از تأیید، `0`.

## ۲) بوت ESP32 — چه باید ببینید

```
[BOOT] Industrial Controller V2.0
[CFG] data-AP='ESP8266_AP'  time-AP='(none)'
[SD] Card OK.
[SD] Resuming from ID ...
[TIME] No time-network saved; will ask the phone instead.
[PORTAL] SSID 'SetClock' -> http://192.168.1.1/
```

✅ **تست ساعت:** با گوشی به وای‌فای `SetClock` (رمز `12345678`) وصل شوید و
`http://192.168.1.1` را باز کنید. صفحه **خودکار** ساعت گوشی را می‌فرستد:

- بالای صفحه ساعت درست نشان داده شود
- در همان صفحه SSID/رمز مودم و اکسس‌پوینت گیرنده را ذخیره کنید (دکمه‌ی اسکن هم هست)
- دکمه‌ی «شروع کار عادی» را بزنید

> اگر تاریخ فایل‌ها باز هم `20250101` شد، یعنی RTC ست نشده — برگردید به همین مرحله.

## ۳) تست ترتیب رله (مهم‌ترین بخش این نسخه)

روی سریال باید **دقیقاً** این ترتیب را ببینید:

```
[CYCLE] ===== Started =====

[TEST] ---- BCM1 (relay pin 2) ----
[TEST] BCM1 attempt 1/3
[TEST] BCM1 این تلاش -> Open:YES Close:YES | مجموع -> Open:YES Close:YES
[TEST] BCM1 OK (در تلاش 1) — تکرار لازم نیست

[TEST] ---- BCM2 (relay pin 4) ----
[TEST] BCM2 attempt 1/3
[TEST] BCM2 این تلاش -> Open:YES Close:NO | مجموع -> Open:YES Close:NO
[TEST] BCM2 JAM (Close نیامده) -> hammering 5x
[TEST] BCM2 attempt 2/3  (فقط برای: Close)
[TEST] BCM2 این تلاش -> Open:NO Close:YES | مجموع -> Open:YES Close:YES
[TEST] BCM2 OK (در تلاش 2) — تکرار لازم نیست

[CYCLE] #1178  BCM1=OK  BCM2=OK  T=24.10 H=41.20 @ 2026-09-28 16:20:11
```

**منطق تکرار:** نتیجه تجمعی است؛ هرچه یک بار تأیید شد دیگر از دست نمی‌رود.
اگر هم باز و هم بسته دیده شد، بلافاصله تمام و دیگر تکراری نیست. اگر فقط یکی
آمد، تلاش بعدی برای همان بخشِ نیامده انجام می‌شود — نهایتاً ۳ بار.

بررسی کنید:

- [ ] کار BCM2 **بعد از** تمام شدن BCM1 شروع شود (هم‌زمان نباشند)
- [ ] رله دقیقاً در طول پنجره‌ی مانیتورینگ فعال باشد (با مولتی‌متر روی کنتاکت)
- [ ] اگر `Open:YES Close:NO` دیدید، یعنی فیدبک Close نمی‌آید → اول سیم پین ۱۵/۱۷
      را چک کنید، بعد `FEEDBACK_WINDOW_MS` و `PULSE_CONFIRM_MS` را بالا ببرید

## ۴) تست ذخیره‌سازی SD

```
[SD] Appended #1178 -> /data/20260928.dat
```

- [ ] فقط **یک فایل در روز** ساخته شود (نه یک فایل برای هر رکورد)
- [ ] اندازه‌ی فایل هر سیکل ۲۵ بایت زیاد شود
- [ ] یک فایل `20260928.pos` هم کنارش باشد

## ۵) تست مسیر آپلود (حالت عادی)

```
[NET] Connected. IP: 192.168.4.2
[UPLOAD] #1178 sent, offset -> 25/25
```

سمت کامپیوتر:

```bash
python app.py        # باید [INIT] templates: ... را چاپ کند
```

- [ ] در سریال Flask خط `[RX] NUM=1178 2026-09-28 16:20:11` بیاید
- [ ] در `http://127.0.0.1:5000` رکورد جدید دیده شود
- [ ] برد را ریست کنید؛ **هیچ رکورد تکراری** در دیتابیس ثبت نشود

## ۶) تست حالت دیتا (گوشی و کامپیوتر باید یکی باشند)

از پورتال «حالت نمایش دیتا» را انتخاب کنید؛ ESP32 اکسس‌پوینت `RF_TESTER`
(رمز `12345678`, آی‌پی `192.168.1.1`) را بالا می‌آورد.

**با کامپیوتر:**

```bash
python dist/RFTester.pyz --web --app-server http://127.0.0.1:5000
# IP=192.168.1.1  Port=80  →  sync10  →  «ارسال به app.py»
```

**با گوشی:** همان APK، همان IP/پورت، همان دکمه‌ی «ارسال به app.py»
(آدرس سرور = آی‌پی کامپیوتر در شبکه، مثل `http://192.168.1.100:5000`).

- [ ] خروجی هر دو **عین هم** باشد (هر دو خط‌های `NUM=...`)
- [ ] جواب سرور: `saved=N, duplicates=0`
- [ ] اگر همان دیتا را با آن یکی دستگاه هم بفرستید: `saved=0, duplicates=N`

تست سریع بدون سخت‌افزار (برای اطمینان از سمت سرور):

```bash
curl -X POST http://127.0.0.1:5000/api/ingest -H "Content-Type: application/json" \
  -d '{"lines":["NUM=1,NBCM1=OK,NBCM2=OK,NBCM3=NOK,NBCM4=NOK,Temp=20.00,Humidity=40.00,Date=2026-09-28,Time=10:00:00"]}'
```

## ۷) تست پایداری (بگذارید بماند)

هر ۳۰ ثانیه:

```
[HEALTH] heap=183204 min=170112 | hb R:12 D:48 S:12 N:9412 | up=1440s
```

- [ ] `heap` در طول چند ساعت **کاهش پیوسته** نداشته باشد (نشت حافظه)
- [ ] `hb N:` مدام زیاد شود
- [ ] `up=` صفر نشود (یعنی ریست نخورده)
- [ ] دستگاه را ۲۴ ساعت روشن بگذارید و آخرش `up=` را ببینید
