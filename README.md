# RF_tester

RFtester

## بخش‌ها

| مسیر | توضیح |
|---|---|
| `app.py` | سرور Flask دریافت سریال + دیتابیس (مستر + روزانه) + API اپ اندروید |
| `esp32_controller_FIXED/` | کد ESP32 (کنترلر رله، SHT31، RTC، SD، وای‌فای) |
| `esp8266_receiver_FIXED/` | گیرنده ESP8266 (AP سریال ↔ شبکه) |
| `android/` | **اپ اندروید دو نود بدنه** — Material 3، نمودار/تحلیل، دیتابیس Room، ارسال آفلاین |

## اپ اندروید (خلاصه)

- داشبورد، نمودارها (خطی/مساحتی/میله‌ای)، تحلیل، تاریخچه، تنظیمات
- ذخیره کامل: زمان، تاریخ، دما (REAL)، رطوبت (REAL)، وضعیت کانال‌ها
- **بدون وای‌فای ذخیره می‌کند؛ به‌محض اتصال به سرور ارسال می‌شود**
- جزئیات: [android/README.md](android/README.md)

### API ویژه اپ (اضافه‌شده به `app.py`)

- `POST /api/ingest` — دریافت بچ خوانش‌های آفلاین (با تشخیص تکرار)
- `GET /api/master_data?limit=N` — دریافت آرشیو با محدودیت تعداد
- `GET /api/app_health` — سلامت سرور
