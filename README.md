# RF_tester

سیستم تست خودکار درب‌های BCM با ESP32 + ESP8266 و سرور ثبت داده.

```
ESP32 (تست رله‌ها، SD، RTC) ──WiFi──► ESP8266 (گیرنده) ──USB/Serial──► app.py ──► SQLite
```

## ساختار پروژه

```
esp32_controller_FIXED/     ← فلش روی ESP32  (رله‌ها، SHT31، RTC، کارت SD)
esp8266_receiver_FIXED/     ← فلش روی ESP8266 (اکسس‌پوینت گیرنده، به USB کامپیوتر)

app.py                      ← سرور
requirements.txt            ← پیش‌نیازهای پایتون
run_server.bat              ← اجرای یک‌کلیکی روی ویندوز
run_server.sh               ← اجرا روی لینوکس/مک
templates/                  ← صفحات وب (index، history، plot_display، upload)

docs/SERVER_SETUP.md        ← راه‌اندازی سرور
docs/FIELD_TEST.md          ← چک‌لیست تست روی سخت‌افزار
.github/scripts/            ← تست‌های خودکار (اختیاری، برای توسعه)
```

فایل‌هایی که خودکار ساخته می‌شوند: `instance/master_industrial.db`،
`YYYY-MM-DD.db`، `.venv/`، و در صورت خطا `unsaved_records.log`.

## شروع سریع

1. `esp8266_receiver_FIXED.ino` را روی ESP8266 فلش و با USB به کامپیوتر وصل کنید.
2. `esp32_controller_FIXED.ino` را روی ESP32 فلش کنید.
3. با گوشی به وای‌فای `SetClock` (رمز `12345678`) وصل شوید و `http://192.168.1.1`
   را باز کنید؛ ساعت خودکار تنظیم می‌شود. سپس دکمه‌ی **«▶ تست رله‌ها را شروع کن»**
   را بزنید. تا این دکمه زده نشود هیچ رله‌ای تریگ نمی‌شود.
4. روی کامپیوتر `run_server.bat` را اجرا و در داشبورد پورت COM را انتخاب کنید.

## امکانات سرور

| صفحه / مسیر | کار |
|---|---|
| `/` | داشبورد زنده: دو ساعت (دستگاه و سرور)، چهار سطح منطقی ۱/۰، تنظیمات پورت و ثبت دستی |
| `/history` | آرشیو با دایره‌های وضعیت + خروجی CSV |
| `/plot_display` | نمودار دما/رطوبت و نمودار دیجیتال چهار سیگنال |
| `/paste` | چسباندن متن خام سریال (تکی یا چندتایی) |
| `/upload_dat` | آپلود فایل `.dat` کارت SD + **ورود همان CSV خروجی** |
| `/save_data` | دانلود پشتیبان کامل دیتابیس |

اجرای پایدار برای کار طولانی‌مدت:

```bash
python app.py --prod
```

## فرمت داده

هر سیکل یک رکورد با چهار نتیجه‌ی تفکیکی تولید می‌کند:

```
NUM=1178,BCM1_OPEN=OK,BCM1_CLOSE=OK,BCM2_OPEN=OK,BCM2_CLOSE=NOK,
Temp=24.50,Humidity=40.00,Date=2026-09-29,Time=11:00:00
```

همین یک فرمت، هم روی سریال به سرور می‌رسد و هم در حالت دیتا به هر کلاینتی
داده می‌شود. مرجع زمان، RTC خودِ دستگاه است.

## فرمان‌های سریال ESP32

| فرمان | کار |
|---|---|
| `STATUS` | وضعیت لحظه‌ای (مرحله، وای‌فای، شماره‌ی رکورد بعدی، حافظه) |
| `FORMAT` | پاک‌سازی کامل حافظه‌ی فعال (SD یا داخلی) |

## روند یک سیکل تست

```
تریگ رله باز  ─► مانیتورینگ BCM1 و BCM2 ─► قطع مانیتورینگ ─► قطع رله
      ↓ (۵ ثانیه از تریگ تا تریگ)
تریگ رله بسته ─► مانیتورینگ BCM1 و BCM2 ─► قطع مانیتورینگ ─► قطع رله
      ↓
ثبت رکورد (۴ نتیجه + دما + رطوبت + ساعت RTC) ─► SD ─► آپلود
```

اگر هر دو دستگاه هم «باز» و هم «بسته» را تأیید کنند، تکرار نمی‌شود؛
وگرنه کل سیکل تا سقف ۳ بار تکرار می‌شود.

## تنظیمات مهم بالای اسکچ ESP32

```cpp
#define LOG_LEVEL 1                 // 0=کمینه ، 1=معمولی ، 2=عیب‌یابی کامل

const uint8_t RELAY_PINS[2] = { 2, 4 };          // رله باز کردن / بستن
const uint8_t FEEDBACK_PINS[2][2] = {
  { 13, 16 },   // فیدبک «باز شد» : BCM1 , BCM2
  { 15, 17 },   // فیدبک «بسته شد»: BCM1 , BCM2
};

const uint32_t RELAY_SETTLE_MS           = 50;      // تریگ تا شروع مانیتورینگ
const uint32_t FEEDBACK_WINDOW_MS        = 3000;    // مهلت پاسخ BCM
const uint32_t PHASE_TRIGGER_INTERVAL_MS = 5000;    // تریگ رله۱ تا تریگ رله۲
const uint8_t  RELAY_MAX_ATTEMPTS        = 3;       // سقف تکرار سیکل
const uint32_t CYCLE_PERIOD_MS           = 120000;  // فاصله‌ی سیکل‌های اصلی

const bool ALWAYS_OPEN_PORTAL = true;   // در هر بوت منتظر دکمه‌ی شروع بماند
```

## واچ‌داگ

| تسک | آستانه‌ی قفل | واکنش |
|---|---|---|
| شبکه | ۹۰ ثانیه | ری‌استارت کنترل‌شده |
| رله / دیجیتال / سنسور | ۳ برابر دوره‌ی سیکل (۶ دقیقه) | ری‌استارت کنترل‌شده |
| لینک قطع بعد از اتصال موفق | ۱۰ دقیقه | ری‌استارت کنترل‌شده |
| شکست نوشتن روی SD | ۵ بار پیاپی | ری‌استارت کنترل‌شده |

## تضمین ذخیره‌سازی

روی دستگاه: نوشتن روی SD مستقل از شبکه، تلاش دوباره با مقداردهی مجدد کارت،
و نوشتن مستقیم اگر صف پر شود.
روی سرور: هر رکوردی که در دیتابیس ننشیند در `unsaved_records.log` می‌ماند و
در اجرای بعدی (یا با `POST /api/recover_unsaved`) برمی‌گردد.
