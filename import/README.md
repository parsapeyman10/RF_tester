# ورود دستی داده‌ها

این پوشه شامل رکوردهای گرفته‌شده از سریال است که به فرمت قابل‌خواندن سرور
تبدیل شده‌اند.

| فایل | کاربرد |
|---|---|
| `20260929.dat` | همان فرمت باینری کارت SD (۲۵ بایت به ازای هر رکورد) — برای صفحه‌ی `/upload_dat` |
| `20260929_lines.txt` | همان رکوردها به‌صورت خط متنی — برای `POST /api/ingest` |

## روش ۱: از طریق مرورگر (ساده‌ترین)

1. سرور را اجرا کنید (`run_server.bat`)
2. به `http://127.0.0.1:5000/upload_dat` بروید
3. فایل `20260929.dat` را انتخاب و آپلود کنید

پاسخ باید چنین باشد:

```json
{"status": "success", "processed": 16, "failed": 0, "skipped_duplicates": 0}
```

## روش ۲: با خط فرمان

```bash
curl -F "folder_upload=@import/20260929.dat" http://127.0.0.1:5000/upload_dat
```

یا از روی فایل متنی:

```bash
curl -X POST http://127.0.0.1:5000/api/ingest \
     -H "Content-Type: text/plain" \
     --data-binary @import/20260929_lines.txt
```

## نکته

آپلود دوباره‌ی همین فایل هیچ رکورد تکراری نمی‌سازد؛ پاسخ
`skipped_duplicates: 16` می‌دهد.
